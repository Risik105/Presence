# Presence

Presence is a lightweight desktop autoclicker for Windows. Configure the click interval and choose to repeat clicks in batches or stop after a set number. The app also includes global keyboard shortcuts, click and elapsed-time counters, and system-tray controls.

## Features

- Repeat clicks in batches or run a limited number of clicks
- Configure the interval between clicks
- Set and change global start and stop shortcuts
- View completed clicks and elapsed time

## Download

Download and extract the release archive, then run the executable from the extracted folder. Keep the full folder together; the standalone build needs its accompanying files.
